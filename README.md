# Troisi Galassia

Plugin WordPress comune a tutti i siti della galassia Troisi Ricerche
(SEO, dati strutturati, Open Graph, GA4 dopo consenso Iubenda, IndexNow,
llms.txt, redirect 301/410, pulsanti Condividi e Stampa).

- `troisi-galassia/` – sorgente del plugin
- `dist/troisi-galassia.zip` – pacchetto installabile
- `update.json` – versione pubblicata: i siti la leggono due volte al giorno
  e si aggiornano da soli quando il numero è più alto di quello installato.
